Написати конструктор __init__ для класа Users. Він повинен задати атрибути name та email для інстансів. Створити інстанс a з ім'ям "Alex"" та поштою "alex@company.com".


Метаклас type

При створенні класа, його метакласом за замовчуванням є type. Коли створюється інстанс класа, викликається type.__call__.

class Users:
    pass

a = Users()
# це є синтаксичним цукором для команди нижче
a = type.__call__(Users)
# або більш універсально, бо метаклас можно і поміняти
a = Users.__class__.__call__(Users)

Атрибут __call__ можна переписати поверх. Наприклад, для функцій виклик __call__ виглядає інакше.

def hello(a, b):
    print(f"Привіт, {a}. Твій email: {b}")

hello("Alex", "email@company.com")
# а це синтаксичний цукор для ще одного визову __call__
hello.__call__("Alex", "email@company.com")

Синтаксичний цукор потрібен, щоб пітон ззовні виглядав схожим на інші мови програмування.

У type атрибут __call__ викликає ще два атрибути всередині себе.

def __call__(...):
    ...
    obj = __new__(...)
    # задає індивідуальну поведінку інстансу
    ...
    __init__(obj, ...)
    # заповнює інстансу прикладні атрибути в __dict__
    ...

Якщо клас перепише зверху атрибути __new__ чи __init__, то він візьме під контроль створення своїх інстансів, оформить їх більш індивідуально.


Конструктор __init__

Змінні, які привласнюються всередині класа, переробляються на атрибути класа. Вони будуть закинуті в __dict__ на етапі створення класа.

class Greeting:
    s = "Hello"

print(Greeting.__dict__) # буде містити змінну s як атрибут

У всіх інстансів буде атрибут з однаковим текстом "Hello". Припустимо, що нам треба при створенні інстанса задати кожному інстансу свій унікальний текст. В такому разі переписують зверху __init__.

class Foods:
    def __init__(self, name, glycemic_index):
       self.name = name
       self.glycemic_index = glycemic_index

a = Foods("Apple", 36) # створюємо інстанс

При створенні інстанса виконається type.__call__(Foods, 'Apple', 36). Він в свою чергу викличе підмінений __init__(self, 'Apple', 36). Завдяки змінній self, клас задасть для свого інстанса індивідуальні значення атрибутів.
