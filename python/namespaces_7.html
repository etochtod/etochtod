Блоки кода

Блок кода - це код, який можна за бажанням виконати пізніше. В пітоні є спеціальний синтаксис для створення змінної, яка буде вказувати на блок кода:

def f():
    s = "Hello"
    print(s)
# змінній f привласнений код, але він ще не виконується.

f() # код виконується. На екрані "Hello"
  • Змінна f вказує на об'єкт з атрибутом __code__, в якому зберігається код.
  • Після def йдуть рядки з відступами. Прийнято задавати їх кратними чотирьом прогаликам.
  • Виконати блок кода можна написав назву змінної плюс дужки.

Блоки кода типово використовують для запобігання повторюваності кода. Якщо якийсь код повторюється в програмі, то його виносять окремо щоб викликати декілька разів.


Простір імен

До цього змінні задавалися в глобальному просторі імен. Якщо змінна задається в блоці кода, то це локальний простір імен. За межами блока кода її не видно. А глобальні змінні всередині блока кода є константами. Щоб все ж таки поміняти глобальну змінну всередині блока кода, треба в блоці додати рядок global some_global_variable.

a = 1

def print_1():
    print(a)
# надрукує 1 як константу

def no_change():
    a = 2
# так і залишиться 1 по виходу з функції

def print_2():
    a = 2
    print(a)
# встигне надрукувати 2, глобально так і лишиться 1

def print_error():
    print(a)
    a = 2
# видасть помилку, бо перший рядок зафіксував константу

def change_global():
    global a
    print(a)
    a = 2
# надрукує 1, і поміняє на 2

Щоб запобігти плутанині глобального та локального простору можна прямо вказувати значення змінних як атрибути об'єктів. Так явно задається простір імен.

def f():
    print(f.greeting)

f.greeting = "Вітаннячко"
# додали прикладний атрибут

f()
# виведе на екран "Вітаннячко"

Глобальні змінні іноді виносять в окремий об'єкт, де вони оформлені як атрибути об'єкта. Припустимо, є об'єкт (файл) globals.py, в ньому є рядок "my_var = 1". Тоді інші файли зможуть імпортувати цей файл рядком "import globals", і далі звертатися до цієї змінної як до атрибуту globals.my_var.


Аргументи та параметри

У дужках у блока кода можуть бути дотаткові змінні, які йому передаються в момент виклика. Змінні перелічуються через кому.

def hello(name, email):
    print(f"Привіт {name}, твій email: {email}")

hello("Alex", "email@company.com")

В момент декларації блока кода такі змінні називаються параметрами. А коли блок кода викликається, то їх називають аргументами.

def hello(txt): # txt - це параметр
    print(txt)

hello("Hello world!") # "Hello world!" - це аргумент

Прості типи даних передаються блоку кода як копія (immutable), складні - за посиланням (mutable).
