# Система управління навчанням

Це безсерверний застосунок для вивчення python. Кілька статичних html сторінок з теоретичним матеріалом та автоперевірками. Сторінка дає теорію, дає завдання по теорії, учень набирає код рішення в пітоні, запускає його на сторінці, і далі сторінка інтерактивно перевіряє чи правильно учень вирішив завдання.

На даний момент це тільки прототип - спроба показати людям з онлайн IT-школ технічну можливість ідеї. Спроба зацікавити долучитися. Повне завдання - охопити оглядово весь матеріал, необхідний для виготовлення свого повноцінного сайта. Для учня планується екскурсія по кухні сайтобудування, огляд та розуміння основних принципів.

Тобто, далі до пітона почне приєднуватися весь backend та frontend. Спочатку, по ходу виконання завдань треба буде встановити на компьютері **python**. Потім знадобиться **nginx**. Потім **postgresql**...

В кінці воно повинно вирости у перший власний сайт з багатосторінковою темплейтною структурою, регістрацією через соціальні мережі, з базою даних, оптимізаціями. Сайт буде зроблений учнем від початку до кінця своїми руками, всі сервери якого будуть функціонувати на його домашньому компьютері.

Контроль та перевірка процесу створення сайту буде лежати на плечах набора статичних сторінок. Спочатку код учня буде вводитися прямо на цих сторінках. А коли доведеться запускати код на окремо встановленому пітоні (із-за безпекових обмежень вбудованого в браузер пітона), то порядок зміниться: учень запускає код, копіює код на статичні сторінки з метою перевірки, вони перевіряють напряму текст коду, а AJAX-запитами перевірять по локальним адресам коректність створення сайта учня.
